# SQL 面试复习手册 设计文档

日期：2026-08-15
状态：已获用户批准

## 1. 背景与目标

sql_practice 项目内有 14 个专题、36 道 SQL 题目（7 道为 stub），题目与参考答案均存于 `data_builder/manifest.py`。用户需要一份可用于**大数据/数仓岗面试准备**的 Markdown 复习文档。

核心诉求：

- 题目不贪多，按知识点精选，每道题做透
- 做题的同时发散复习相关知识点（同题型变式、多解法对比、相关函数、面试追问）
- 支持自测：先自己想，再点开答案

## 2. 需求决策记录

| 决策点 | 结论 |
|---|---|
| 使用场景 | 大数据/数仓面试准备，以 Hive SQL 面试口径为准 |
| 题量 | 按知识点精选 22 道（覆盖全部知识点，不重复） |
| 自测形式 | 答案与解析放入 `<details>` 折叠块 |
| 发散深度 | SQL 层面延伸 + 面试追问；不展开底层执行原理 |
| 组织方案 | 双部分结构：Part 1 知识速查 + Part 2 精选题册 |
| 文件位置 | `docs/sql-interview-review.md`（单文件） |

### 3.1 Part 1 知识速查

只放结论性速记，不放推导（推导和细节归 Part 2 题目）。

- **1.1 窗口函数家族总览**（表格）
  - 排序类：`row_number` / `rank` / `dense_rank` 三者并列处理与是否跳号的对比
  - 前后类：`lag` / `lead`（含 offset、default 参数）、`first_value` / `last_value`
  - 聚合开窗：`sum` / `min` / `max` / `count` / `avg` OVER(...)
  - 窗口帧：`ROWS BETWEEN ... AND ...`（unbounded preceding / current row / n following）
- **1.2 经典题型模式速查**（最核心的表）：每行 = 套路名 + 核心口诀 + 对应题号
  - 连续问题三板斧（row_number 差值法 / lag 判定法 / 自关联）
  - 留存计算（首活日期 + left join + 条件计数）
  - 同时在线（进出事件 UNION ALL (+1/-1) → 累计求和 → 峰值）
  - 区间合并/交集、行转列/列转行、第 N 高、波峰波谷、forward fill
- **1.3 JOIN 类型速查**：inner / left / full / 自关联 / 非等值 join，各附典型题号
- **1.4 日期与字符串函数速查**：`date_add` / `date_sub` / `datediff` / `substr` / `instr` / `group_concat` / `round` 等
- **1.5 高频面试追问清单**：
  - 窗口函数 vs GROUP BY 的区别
  - COUNT(DISTINCT) 的数据倾斜问题与解法
  - 千亿级 join 优化思路（map-side join / 分桶 / Bloom filter）
  - Hive SQL 与标准 SQL 的常见差异

### 3.3 每题模板

```markdown
### Q<n>. <题目标题>  `来源标签` `难度 n`

<表结构（3-5 行精简版，含示例数据 2-3 行）>

<题目描述>

提示：<弱化展示的提示>

<details><summary>💡 思路与答案（点开前先自己想 5 分钟）</summary>

**1. 解题思路**：先说套路，再讲步骤（3-5 行）

**2. 参考 SQL**（分步注释，Hive 方言）

**3. 关键解析**：只在"为什么这么写"的行上注释，不逐行复读

**4. 知识点延伸**：
   - 同题型变式：...
   - 多解法对比：...
   - 相关函数：...

**5. 面试追问**：1-3 个 Q&A

</details>
```

### 3.4 方言规范

- 统一采用 **Hive SQL 面试口径**撰写答案
- manifest 中 SQLite 风格写法（`strftime`、`julianday` 等）改写为 Hive 标准（`date_add`、`datediff`、`months_between` 等）
- 必要时在题目内附一行"SQLite 等价写法"备注，保持与项目本地练习环境的对应关系

## 4. 实现要点

- 数据来源：`data_builder/manifest.py` 中对应 Problem 的 description、reference_sql、hints、tables 字段；表结构参考各 `databases/*.db` 与 `data_builder/builders/*.py`
- 22 道题与速查表内容较多，实现时分批写入（先 Part 1，再按组分批写 Part 2），避免单次输出截断
- 文档中的题号（Q1-Q22）与项目题目 id（如 01_01）同时标注，方便回项目重做
- stub 题目（12_xx、14_02、14_04）不收录
